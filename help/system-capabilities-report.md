# Capabilities Report

> **[Open this page in Quilltap](/settings?section=capabilities-report)**

The Capabilities Report has been renamed, expanded, and given a proper spine. It is now **[The Almanack](the-almanack.md)** — the same dossier of your establishment, brought up to date with the parts of the application the old report had never learned to look at, and considerably enlarged in the process.

This page remains so that old links and old bookmarks arrive somewhere sensible rather than nowhere at all.

**→ [Read The Almanack's documentation](the-almanack.md)**

Everything you knew still holds: you will find it in the same place (Settings → Data & Maintenance → The Almanack), the button still compiles a comprehensive report of your system, previous editions are still listed, viewable, downloadable and deletable, and the result is still designed to be safe to share in a bug report. What is new is the coverage — the Scriptorium, the dramatis personae, the wire records — and a progress bar that names the phase it is working on rather than spinning at you.
