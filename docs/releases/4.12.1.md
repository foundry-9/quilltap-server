# Quilltap 4.12.1 Release Notes

Ask a character what happened at the lighthouse last Tuesday, and until now the poor soul would rummage through every memory they had ever made of the lighthouse, pick the most promising few hundred, and only *then* check the calendar. If last Tuesday's visit was not among the favourites, it was simply not there, and the character would declare, with the serene confidence of a man who has lost his spectacles on his own forehead, that they had no recollection of the matter whatsoever. In 4.12.1 the house consults the diary first: a `search` with a date range (and the recall for a turn that looks backward in time) gathers the memories and conversations from that period before anything else is weighed, and for a span of a fortnight or less the dates themselves are taken as proof enough of relevance.

And when a dated search does come back empty, it now says *why*. Either nothing matched the words, or nothing happened in that period at all — and if conversations did take place then, it names them, so the character can go and read the transcript rather than shrugging. Characters are told, in so many words, to look before they claim they cannot remember. Undated searches are untouched, and no data or export format has changed. Behind the curtain, the CI test run was also given a larger heap, having grown too stout for the old one.

## Installation

### Electron Desktop App

Download the latest `.dmg` (macOS), `.exe` (Windows), or `.AppImage` (Linux) from the [quilltap-shell releases page](https://github.com/foundry-9/quilltap-shell/releases/latest). The window is only ever a front end, and it offers three back ends: **Direct** (the Node server inside Electron, no isolation), **Docker** (the container image behind a native window, which is the recommended setup and the strongest boundary we ship), and **Remote** (any Quilltap URL, including a dev server, an `npx quilltap` instance, or a machine on your network). Requires shell 4.2.0 or later.

### npm (Node 24 required)

```bash
npm install -g quilltap
quilltap
```

Open `http://localhost:3000` in your browser. Requires Node.js 24+, and on Linux glibc 2.35+. First run downloads and caches locally.

### Docker

```bash
docker pull foundry9/quilltap:4.12.1
```

Or use the startup scripts:

```bash
# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/foundry-9/quilltap-server/refs/heads/main/scripts/start-quilltap.sh | bash

# Windows (PowerShell)
irm https://raw.githubusercontent.com/foundry-9/quilltap-server/refs/heads/main/scripts/start-quilltap.ps1 | iex
```

### Standalone Tarball

Available for environments where npm global installs and Docker are both impractical. See the GitHub releases page for download links.
