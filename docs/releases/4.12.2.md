# Quilltap 4.12.2 Release Notes

It has come to our attention, by way of the household accounts, that the establishment has been paying to put the same chat history into the larder every evening and then never once taking it out again. Anthropic's and OpenAI's prompt caches were being written faithfully and read hardly at all: the Brahma Console, `@Brahma`, the Scenario Builder and help chat left the profile's cache settings at the door, and in the Salon the cache marker sat on the one message that changes every turn. In 4.12.2 the Anthropic plugin marks the message before the final one, the OpenAI plugin marks every stable boundary on GPT-5.6 and later (and stops chasing a `previous_response_id` that was never stored), and the Character Optimizer sends its shared context as one unchanging message so every pass after the first reads it back. Its log rows now say what each call cost, too.

The OpenRouter plugin, deprived overnight of a function its SDK had quietly withdrawn, now streams every turn over Chat Completions directly, and streaming tool and image turns finally carry the zero-data-retention flag and the other provider preferences they had been leaving in the cloakroom. The Green Room no longer dresses a character in the same outfit for every party, nor in two complete outfits at once, which was never the look anyone intended. Gemini's honest answers about an imported photograph are no longer thrown out on suspicion of not having seen it. And the Docker image has moved its production stage from Debian bookworm to Wolfi, shedding a critical and some ten high-severity findings that Debian had no fix for. Anyone who layers extra tools onto the image should now say `apk add` where they once said `apt-get`.

## Installation

### Electron Desktop App

Download the latest `.dmg` (macOS), `.exe` (Windows), or `.AppImage` (Linux) from the [quilltap-shell releases page](https://github.com/foundry-9/quilltap-shell/releases/latest). The window is only ever a front end, and it offers three back ends: **Direct** (the Node server inside Electron, no isolation), **Docker** (the container image behind a native window, which is the recommended setup and the strongest boundary we ship), and **Remote** (any Quilltap URL, including a dev server, an `npx quilltap` instance, or a machine on your network). Requires shell 4.2.0 or later.

### npm (Node 24 required)

```bash
npm install -g quilltap
quilltap
```

Open `http://localhost:3000` in your browser. Requires Node.js 24+, and on Linux glibc 2.35+. First run downloads and caches locally.

### Docker

```bash
docker pull foundry9/quilltap:4.12.2
```

Or use the startup scripts:

```bash
# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/foundry-9/quilltap-server/refs/heads/main/scripts/start-quilltap.sh | bash

# Windows (PowerShell)
irm https://raw.githubusercontent.com/foundry-9/quilltap-server/refs/heads/main/scripts/start-quilltap.ps1 | iex
```

### Standalone Tarball

Available for environments where npm global installs and Docker are both impractical. See the GitHub releases page for download links.
