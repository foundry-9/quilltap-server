# Appearance Settings

> **[Open this page in Quilltap](/settings?group=appearance)**

The Appearance group of Settings is where you customize how Quilltap looks and feels. Here you can change themes, select your preferred color mode (light/dark/system), reach the theme picker (open **Studio** and choose **Theme…**), and adjust sidebar width.

## Dynamic Backgrounds

The **Dynamic Backgrounds** card hangs a changing collage of your own generated pictures behind the home parlour, each project and each character. It is off until you switch it on, and it pays no attention to the theme. See [Dynamic Backgrounds](dynamic-backgrounds.md).

## Accessing Appearance Settings

1. Click **Settings** (gear icon) on the rail
2. Open the **Appearance** group in the left rail
3. You'll see options for themes, color modes, and layout controls

## Theme Selection

### Understanding Themes

Quilltap includes a default theme, a set of bundled themes, and any `.qtap-theme` bundles you install:

- **Default theme** — Professional, clean design (always available)
- **Bundled and installed themes** — Further designs, from the ones that ship with Quilltap to bundles you have added yourself
- **Color modes** — Each theme can be viewed in light or dark mode
- **Icons and small animations** — A theme may re-cut the icons themselves, and even the little flourishes that move

### The Waiting Quill

While a character gathers their thoughts — and again while the words are actually arriving — a small quill keeps you company. By default it rocks upon its nib, as though poised over the page mid-sentence.

A theme is entitled to its own opinion on the matter. It may substitute its own mark and give it quite a different motion: **Madman's Box**, for instance, declines to write at all, and instead turns its ringed quill slowly through a full revolution, in the manner of a rotor idling in the corner of the cabin. Should you have asked your system to reduce motion, the quill holds admirably still in every theme.

### Viewing Available Themes

In the Theme Selection section, you'll see:

- **Theme cards** — Each theme displayed in a grid
- **Color preview** — Sample colors for each theme
- **Theme name** — What to call the theme
- **Description** — What makes this theme unique
- **Dark mode badge** — Whether the theme supports dark mode
- **Active indicator** — A checkmark on the current theme

### Designing a Theme of Your Own

The **Design a theme** button at the head of the Theme section opens [Calliope's Atelier](theme-editor.md), where you may begin a theme from a blank canvas or a copy of one in your wardrobe, see the whole of Quilltap wear it while you choose its colours, and install it when it suits.

### Selecting a Theme

1. Browse the available themes
2. Click on a theme card to select it
3. The checkmark moves to show the new selection
4. Your interface updates instantly with the new theme
5. Your choice is saved automatically

### Expanding Theme Details

Some themes may have additional details:

1. Click the theme card or the expand button
2. See more information about the theme
3. View color palette details
4. Read a full theme description
5. Click to collapse again

### Installing More Themes

To get more themes:

1. Click **Install Theme** on the Appearance card and choose a `.qtap-theme` file, or browse a theme registry from the same card
2. The new theme appears on the shelf at once

### Garments Left at the Door

A theme made for an earlier Quilltap — a version 1 bundle, or a theme supplied by a plugin — can no longer be worn. Rather than vanish without a word, it is listed beneath the shelf under **Garments Left at the Door**, with an explanation, a button to the Themes help page and, for a bundle, an **Uninstall** button. Nothing is removed unless you press it. Should the theme you had chosen be one of these, Quilltap returns to the Default theme and says so once. The [Themes](/settings?section=appearance) help page explains the particulars.

## Color Mode Selection

### What are Color Modes?

Color modes determine whether Quilltap uses light or dark styling:

- **Light Mode** — Bright backgrounds, dark text (daytime use)
- **Dark Mode** — Dark backgrounds, light text (nighttime use)
- **System** — Automatically matches your computer's setting

### Available Modes

Below the theme cards, you'll see three color mode options:

- **☀ Light** — Always use light colors
- **☀ Dark** — Always use dark colors
- **◐ System** — Follow OS preference (recommended)

### Choosing a Color Mode

1. Find the color mode section
2. Click the radio button or option for your preference
3. The checkmark shows the current selection
4. Your interface updates instantly
5. Your choice is saved automatically

### System Mode (Recommended)

System mode is recommended because it:

- **Automatically switches** when your OS switches between light/dark
- **Reduces manual switching** — You don't need to remember to change it
- **Matches your environment** — Light during day, dark at night (on most systems)
- **Consistent** — Same as your other applications

### Manual Modes

Choose Light or Dark mode manually if you:

- **Always prefer one mode** — Regardless of time of day
- **Don't want automatic switching** — Want consistent appearance
- **Have custom OS settings** — Your OS doesn't switch automatically

## Theme Quick-Switcher

The theme picker is always at hand — no setting enables it. Open **Studio** and choose **Theme…** to switch themes or colour modes at any moment without opening Settings.

See the [Theme Quick-Switcher help file](theme-quick-switcher.md) for detailed instructions.

## Sidebar Width Control

### Current Width Display

The sidebar width control shows:

- **Current width** — The current sidebar width in pixels (e.g., "280px")
- **Visual indicator** — Shows your width compared to default
- **Reset button** — Restore the default width if needed

### Adjusting Width

You can adjust sidebar width in two ways:

#### Method 1: Drag the Resize Handle

1. Position your cursor at the right edge of the sidebar
2. The cursor changes to a resize cursor (↔)
3. Drag left or right to adjust width
4. Your preference is saved automatically

#### Method 2: Via Settings

1. In Appearance settings, find the sidebar width section
2. See your current width
3. Click the "Reset" button to restore default width (if you've customized it)
4. Or use the drag method for precise control

### Minimum and Maximum Widths

- **Minimum** — Around 200px (keeps content readable)
- **Maximum** — Adjustable based on your screen size
- **Default** — Optimized for most use cases

### Why Adjust Width?

Adjust your sidebar width to:

- **Add more space** — Make sidebar wider for easier reading
- **See more content** — Narrow sidebar to view more main content
- **Fit your screen** — Adapt to different screen sizes
- **Customize layout** — Match your personal workflow

### Resetting to Default

1. Find the sidebar width section in Appearance settings
2. Click **Reset to Default** (if available)
3. Your sidebar returns to standard width
4. Other settings unchanged

## Layout Display Options

### What This Section Shows

The layout section may display:

- **Current sidebar width** — Your selected width
- **Collapse button location** — Where sidebar collapse button is
- **Responsive indicators** — How layout adapts to screen size
- **Visual preview** — How your current layout looks

### Sidebar Collapse

Your sidebar can be collapsed to show only icons:

1. Look for the collapse button at the top of the sidebar
2. Click to toggle between expanded and collapsed modes
3. Collapsed mode saves space for main content
4. Icons show labels on hover
5. Your collapse preference is saved

### A Word on Tooltips

The little labels that appear when you rest the pointer on a button are Quilltap's own, not the browser's. They arrive after a short pause, and they take their leave the moment the pointer wanders elsewhere, you click anywhere, press **Esc**, or step away to another window. Reach a control by **Tab** and its label appears and stays put until you move on; a mouse click, or a dialog handing focus back to the button that opened it, summons no label at all. On a touch screen, a tap does not raise one.

## Debug and Development Features

### Development Settings (if visible)

Some installations may show debug features:

- **Theme state display** — Current theme information
- **CSS variable testing** — Visual test of theme colors
- **Configuration details** — Technical theme information

These are useful for developers and are usually hidden in production.

## Calliope

The **Calliope** card ([open it](/settings?section=calliope)) sets two things for the muse who attends the theme editor: **Calliope's engine**, the connection profile her conversations start on (your default unless you name another, and one that permits tool use), and **Let Calliope take up to … turns**, how many steps she may take on one request. What she does, and how her proposals are tried, kept and discarded, is in [Calliope's Atelier](theme-editor.md#calliope-herself).

## Preferences Are Saved Automatically

All Appearance settings are saved automatically:

- **Theme choice** — Your selected theme
- **Color mode** — Light/dark/system preference
- **Quick-switcher state** — Enabled or disabled
- **Sidebar width** — Your custom width
- **Collapse state** — Expanded or collapsed sidebar

Your preferences persist across sessions when logged in.

## How Appearance Settings Work Together

### Theme + Color Mode

The combination works as:

1. **Select a theme** — Defines colors, fonts, component styles
2. **Select a color mode** — Determines if those colors are light or dark
3. **Both apply together** — Theme provides the design, color mode applies it

For example:

- Earl Grey theme + Light mode = Earl Grey theme's light color palette
- Earl Grey theme + Dark mode = Earl Grey theme's dark color palette
- Same theme, different modes = Different appearance

### Quick-Switcher + Settings

- **Settings** — Full control and information
- **Theme picker (Studio → Theme…)** — Faster switching without opening Settings
- **Both ways work** — Changes in one are reflected in the other
- **Choose your method** — Use whichever fits your workflow

### Legibility and Motion

Every theme the house supplies — in light dress and dark — is held to the customary standard of legibility: ordinary text stands at least four and a half times brighter (or darker) than the ground beneath it, and focus rings and other signposts at least three. You will notice the consequences chiefly in the status colours. In light mode, success, warning and information messages wear a deeper shade so they may be read rather than merely glimpsed; in dark mode the red "delete" buttons and their green and blue cousins are lighter, with dark lettering upon them. Art Deco and Great Estate, finding gold lettering illegible on cream, now set their links and the active tab in bronze in light mode, and the gold focus ring in Art Deco is likewise burnished.

Should you have asked your operating system to reduce motion, every theme now obliges — not only the default — and the various pulses, slides and spinners settle down to a single, nearly instantaneous gesture.

Notices that appear in the corner (the little toasts announcing a save or a mishap) now wear the theme's own status colours and are read aloud by screen readers, and dialog boxes take the keyboard's attention when they open, keep it while they are open, and hand it back politely when they close.

That courtesy now extends to every dialog in the house, not merely the principal few: each one announces itself to a screen reader by its title, keeps the Tab key circulating within its walls, closes at a touch of Escape, and returns you to the very button that summoned it. The floating Help and Console windows take your attention on opening but do not hold it hostage — the page behind them stays within reach of Tab, and Escape dismisses them wherever you happen to be, unless a proper dialog is open and has the prior claim.

Nor need you reach for the mouse to open things. The name on a character card, a document store's title, a folder or a file in the Scriptorium's lists, an entry in the LLM log, a picture in a gallery and a document's title (to rename it) may all be reached with Tab and set going with Enter or the space bar.

The very first press of Tab on any page now offers a **Skip to content** link, so the keyboard may bypass the sidebar entirely and land in the page proper. In the Salon, a screen reader is told each time a character replies, and Document Mode murmurs "Saved" when your work is safely put away. A whisper you are merely overhearing says so in words, not just in a paler ink, and the close buttons on workspace tabs have grown large enough to hit without squinting. Should your system be set to Windows High Contrast, the icons now keep their ink rather than vanishing into the page.

## Troubleshooting Appearance Settings

### Themes Won't Load

**Problem:** A theme you expected is missing from the shelf

**Solutions:**

- Look under **Garments Left at the Door**: a theme made for an earlier Quilltap, or supplied by a plugin, is listed there instead
- Refresh the page
- If you installed the bundle yourself, install it again; a failed install says why

### Color Mode Changes Don't Apply

**Problem:** Switching between light/dark doesn't work

**Solutions:**

- Refresh the page
- Check your internet connection
- Make sure you're not in a special UI mode
- Try switching themes to see if that works

### Sidebar Width Won't Change

**Problem:** Dragging the sidebar resize handle doesn't work

**Solutions:**

- Ensure you're grabbing the right edge of the sidebar
- Look for the resize cursor (↔) before dragging
- Try adjusting in the opposite direction slightly first
- Refresh the page if stuck

### Changes Not Saving

**Problem:** Appearance settings don't persist

**Solutions:**

- Check your internet connection
- Verify you're logged in
- Try making the change again
- Check if local storage is available in your browser
- Look for browser console errors

## Tips for Best Results

1. **Try System mode** — Let your OS handle light/dark switching
2. **Match your workflow** — Choose themes that match your creative style
3. **Experiment** — Try different themes to find your favorite
4. **Use the theme picker if you switch themes** — Studio → Theme… makes switching fast
5. **Adjust sidebar width to your needs** — Find what's comfortable for you
6. **Use both Settings and the Studio theme picker** — Each has advantages

## In-Chat Settings Access

Characters with help tools enabled can read your current appearance settings during a conversation using the `help_settings` tool with `category: "appearance"`. This returns your theme preference, avatar display mode and style, tag styles, and sidebar width. Ask a help-tools-enabled character something like "What are my appearance settings?" and it will report back.

## In-Chat Navigation

Characters with help tools enabled can navigate directly to this page:

`help_navigate(url: "/settings?group=appearance")`
