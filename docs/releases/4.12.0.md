*4.11 handed the actors their props and gave you the floor. A character could carry a lantern, bid for a turn, and be stopped mid-sentence by a red octagon. What 4.11 could not do was let you settle anything. If you wanted the storm to have broken overnight, you had to say so as a person in the room, and every character was free to doubt you, forget you, or argue. And as the house filled up with stores, garments and objects, the only way to find a thing was to remember where you had put it.*

*4.12 is the release in which your word becomes law, and the house learns to keep its shelves in order.*

---

Where 4.11 let you say "stop," 4.12 lets you say "so it is."

**Deus Ex Machina** is the headline. You can now post a line as **established fact**. It is true in the story, every character knows it whether or not they were in the room, nobody verifies it, and it outlasts the summary and the memory pass. You can say it from your own seat, or post it as the world itself, with no speaker at all. Arm it with `/deus`, with a small toggle on your portrait in the composer, or with ⌘/Ctrl + Shift + Enter.

**One folder browser** is the second. The Scriptorium, Document Mode's picker, the project's file card, the attachment picker, the Wardrobe and the Inventory now browse with the same library. Each has a breadcrumb, folder rows, search, select mode, and a ⋮ menu on every row. Files that are not text, such as pictures, PDFs and Word documents, now open in a read-only viewer instead of failing.

**Search** is the third. With a Salon chat open, the search bar looks in **this conversation** first and highlights every match in the transcript. A message found by global search now opens scrolled to that message, which it never did before. Global search also stops returning the Commonplace Book's whispers and the Host's announcements as if a character had said them (#121).

The rest of the cycle went to the people in the room. **Companion characters stop keeping you on probation**: no more tallying your slips, attaching terms to a yes, or telling you what you "really" meant, and an apology, once accepted, is remembered as settled. A **raised hand** now shows its progress above the composer, and a character who yields with a gesture, *(a tilt of the head, go on, then)*, is understood to have yielded. A connection profile can **cap the images** a turn sends, so a vision model that refuses a fifth picture no longer fails the whole turn.

The rest happened below the floorboards. **Anthropic profiles** move to the 2026-10-21 API version, which no longer accepts temperature or top-p. **Filesystem stores** stop holding a file open for every file they watch, which had been enough to stop the server, and stop downloading the whole of an iCloud Drive to index it. The **database driver** now ships prebuilt for every platform, so nothing compiles on install.

Four changes are worth reading before you upgrade, and all four are under **Upgrading**: Anthropic profiles lose their **temperature and top-p**; every profile now sends **at most four images** per request until you raise it; `npx quilltap` on Linux now needs **glibc 2.35**; and the **search index is rebuilt** on first boot.

The thesis is simple: *4.11 let you say "stop." 4.12 lets you say "so it is."*

## Deus Ex Machina

### Established Fact

Until now, everything you posted was said by someone. If you wrote, as your persona, "The bridge washed out in the night," the characters heard a person claim it, and a person can be mistaken. A cautious character might go and look. A forgetful summary might drop it. A character who was not in the room never heard it at all.

An **established fact** is a different kind of line. It is true in the story and known to everyone. There are two ways to post one:

- **From your seat.** Arm the composer with `/deus`, or with the small toggle in the corner of your portrait, and your next line is posted as fact. A chip above the composer and a tinted frame show that it is armed, and Send reads *Send as established fact*. It disarms after one send. ⌘/Ctrl + Shift + Enter sends a single line as fact without arming anything. In the Salon, the line wears a *Deus Ex Machina* ribbon.
- **From nowhere.** The Insert Announcement dialog has a fourth tab, **Deus Ex Machina**, which posts the fact with no speaker, as a full-width band across the transcript. When every character in the room can see the Staff, the Host makes it known. When any of them cannot, it arrives with no speaker at all.

### Everyone Knows

An established fact goes where an ordinary line does not. It reaches characters who were absent when it was posted and characters who joined later, past the cut that normally hides earlier history from them. The context summary keeps it as its own turn and carries it forward as settled truth. Memory extraction does the same. A fact posted from nowhere is also written straight into every character's memory, word for word, as a manual memory that maintenance treats like one you wrote yourself.

At the end of each turn, a character is reminded of every fact posted since she last spoke, oldest first. When there are none, the reminder adds nothing, so a chat that never uses Deus Ex Machina sends exactly what it did before.

The name is for you. No model is ever told it is reading "Deus Ex Machina"; it is told only that this is how things are.

## A Place for Everything

### One Folder Browser

The Scriptorium's file table, Document Mode's picker, the Wardrobe and the Inventory each had a browser of their own, with their own menus, gaps and bugs. They now share one. A store's page in the Scriptorium has:

- a breadcrumb and folder rows, empty folders included;
- search across the whole store;
- select mode, with batch **Move**, **Copy** and **Delete**;
- a ⋮ menu on every file: Open, Rename, Move to…, Copy to…, **Hard link to…**, **Where else this appears…**, Unlink, Edit description…, Open in Pascal's Workbench, Download and Delete;
- a ⋮ menu on every folder: Rename, Move to…, Copy to… and Delete. Delete removes the folder's contents too, and the confirmation says so.

Folders can now be copied and moved between stores, and a copy or move that fails partway is undone. **Hard links** are offered only where they can work. **Unlink** takes a file out of its link group; it keeps its content and goes its own way on its next save. The menus are proper menu buttons: arrow keys move between entries, and Escape closes the menu without closing the dialog behind it.

The Inventory gains **Copy to folder…**, and its editor's Folder field becomes a folder picker, as the Wardrobe's already was.

### Read-Only Viewers

Pictures, PDFs, Word documents and other files that are not text now open in Document Mode **read-only**, under a ribbon with Download and Close, instead of being read as text and failing. The Scriptorium previews the same files in place. A Word document is rendered to HTML and cleaned before it is shown.

### Document Mode's Libraries

The Open Document picker browses with the same folder browser, and **Go there** switches stores when the chat can reach another. **Project library** opens the project's own store. **General library** opens Quilltap General. Before, every pick from it failed, because it opened a folder that no longer exists.

A Markdown, text or JSON file uploaded into a database store can now be opened and edited in Document Mode; the first save turns it into an ordinary document. Other text kinds in a database store, such as YAML and HTML, open read-only rather than failing on save.

### Changes from Outside

A filesystem store changed outside Quilltap, in Finder or an editor, now refreshes any browser that has it open. Moving a folder in a filesystem store now moves its listing with it, and deleting one removes it; before, the old path lingered in the store.

## Finding Things

### This Conversation First

With a Salon chat focused, the header search bar shows a **This conversation** group above the global results, which are now headed **Everywhere**. It lists the messages in the visible transcript that contain your query, newest first, with speaker, time and excerpt, and every occurrence in the transcript is highlighted as you type. Choosing a match scrolls to it and flashes it, even if it is far up the conversation or folded inside a chip. The full search dialog has a *This conversation* chip for up to fifty matches. Escape closes the dropdown; a second Escape clears the query.

### Links That Land

A message found by global search opens its chat **scrolled to that message**. Before, the link opened the chat at the bottom and the message was left for you to find. If the message is one this view does not show, such as a whisper to someone else or another swipe of a reply, the Salon says so instead of doing nothing.

### Only What Was Said

Global search returned the Staff's messages, the Commonplace Book's recall whispers, the Host's and the Librarian's announcements, as if a character had said them, including whispers meant for other participants (#121). It now returns only lines that a character or you actually wrote. The index is rebuilt once on first boot.

## Off Probation

Characters who had been running for months with a user often began keeping a ledger. They counted your slips, put conditions on their yes, corrected small things, told you what you "really" meant, and never quite finished forgiving. Part of the cause was in Quilltap's own words: the companion guidance told a character to remember "the times {{user}} was right as readily as the times they slipped," and models read that as an instruction to keep score.

That line is gone. The guidance now says there is no ledger. Forgiveness given is finished, an ordinary request gets a yes, a want is said without conditions, and disagreement is kept for things that matter. A new universal rule says a character never tells you what you really meant or felt; she asks. The **Character Optimizer** now counts probation behaviour as drift and will not write warmth up as a risk. The sample prompts that ship with Quilltap (21 of them) are revised to match, and the group-scene rules now aim at characters echoing one another, not at a plain yes to you.

The **Commonplace Book** learns about **repairs**. An accepted apology, a forgiveness or an amends is recorded as a resolution that names what it resolves, and it is scored at least as high as the offence. Only the forgiving party's own words count. When memories are consolidated, an offence and its later repair are folded into one memory that leads with the resolution. Old offences that have been resolved are marked as such and recalled less often. Nothing is deleted, and nothing is re-embedded. Kept promises and "she turned out to be right" are now remembered instead of being skipped as generic warmth.

Existing characters and your own copies of the prompts are not changed. Run the Optimizer on a character who has taken to keeping score.

## In the Salon

### A Raised Hand You Can Watch

Raising your hand used to give you nothing to watch but the button's pulse and, at the end, a short toast. A chip above the composer now follows it: **raised**, then **being weighed** by the character it was put to, then **yielded**, **carried on**, or **nobody asked**, if the reply ended with the hand still up. The outcome stays until you dismiss it, send or nudge, and screen readers hear each step.

Models asked to yield often do it with a gesture, *\*(a tilt of the head, go on, then)\**, and leave out the word they were asked to say. That used to count as carrying on. A short reply that is one stage direction and nothing else is now a yield, and the gesture is kept as the reply.

### At Most So Many Pictures

Some vision models refuse a request with more than four images, and a Salon turn could easily carry more: your new uploads, uploads the character had not yet seen, and every Lantern picture since she last spoke. When that happened, the whole turn failed. A connection profile now has **Most images per request** (default 4). The newest images are sent; older ones are replaced by their descriptions. Each understudy in a fallback chain gets the request trimmed to its own cap.

### Smaller Courtesies

- **Click a character's portrait** in the transcript to see it full size, in the same viewer Aurora's announcements use. Beneath the name, the portrait now lists **what she is carrying**, by glyph, each with a tooltip.
- **The header compacts a crowded cast.** When the breadcrumb runs out of room, character and project names step down to abbreviations, then to avatars, with tooltips for the full name. The title and the backdrop thumbnail always stay.
- **Composer tooltips are Quilltap's own.** The native ones did not reliably appear in the desktop app. Icon-only buttons that relied on them for a name now carry a proper label.
- **Mail deliveries and Pascal's rolls** stay expanded in the transcript, as intended. Two parts of the Salon disagreed about the rule, and they drew as collapsed chips.
- **Dropdowns and menus are opaque.** On Art Deco, Great Estate and Madman's Box, several pickers and menus took the page's see-through background. An open ⋮ menu could also be drawn under the next row, which then took its clicks. Both are fixed, and menus in scrolling lists open upward when there is no room below.
- **Layered dialogs close one at a time.** A click or an Escape in a dialog on top no longer also closes the dialog beneath it.

## Pascal and the Wardrobe

### Presets Follow the Tools

A custom tool's saved run presets could only be read from, and saved to, the running character's own vault, even when the tool itself lived in a group, project or Quilltap General. Presets are now found where tools are: character, group, project, general, nearest first, with a nearer preset shadowing a farther one of the same name. The run dialog labels each preset with its store, and a new **Save into** selector chooses where a preset goes.

### The Green Room Dresses Properly

When a character dressed herself at the start of a chat, the model often listed a dress, which covers top and bottom, under only one slot, and the other slot was left empty. A garment that covers several slots is now worn in all of them.

## Under the Floorboards

### Anthropic's New API Version

The Anthropic plugin (1.0.64) now speaks API version **2026-10-21**. That version refuses `temperature`, `top_p` and `top_k` on every model, so the plugin no longer sends them. The profile editor hides the Temperature and Top P sliders for Anthropic profiles, and a migration removes the stored values. Models that used to receive them now sample at the API's defaults. The new version also refuses a document attached to an assistant turn, so such documents are moved into the user turn just before it. Thinking is unchanged.

Behind this is a new provider capability in `@quilltap/plugin-types` 2.10.0, `samplingParameters`. A provider that declares it `false` gets the same treatment everywhere, from the editor to auto-configure, import and restore.

### Filesystem Stores, Lighter

On macOS, the store watcher opened a file descriptor for every file and folder it watched. A store pointed at a 24,000-file Documents folder held over fifteen thousand descriptors, and the server then failed every request that needed a compile. Filesystem stores now watch with the operating system's own recursive notifications, which hold almost nothing open. The `chokidar` dependency is gone; the instance's own `files/` watcher moved to the same mechanism.

The same store, sitting on iCloud Drive, had been downloading every evicted file in order to index it, and the startup screen waited up to five minutes on it. Evicted iCloud placeholders are now skipped and keep their existing index entries until they are downloaded again. Filesystem stores are scanned after the startup screen releases rather than before.

### A Driver That Needs No Compiling

The encrypted-database driver moves to `better-sqlite3-multiple-ciphers` 13, which ships one prebuilt binary per platform inside the package. The driver is never compiled on install (node-pty still compiles on Linux), the CLI no longer rebuilds the driver, and when the driver cannot load, it says why (no binary for this platform, an old glibc, or the loader's own error) and what to do. Databases open in either version, and the 4.2.x desktop shell, which supplies its own copy of the old driver, keeps working. The server logs the driver and SQLite versions when it opens the database.

### For Plugin and Theme Authors

`@quilltap/plugin-types` 2.10.0 adds `samplingParameters?: boolean` to provider capabilities (omitted means `true`). The default-system-prompts plugin (1.1.30) carries the revised sample prompts. Over the cycle, theme-storybook moved from 1.0.90 to 1.0.96 and create-quilltap-theme to 2.0.23. They mirror the new `qt-bg-popover` utility and its `--qt-popover-bg` variable; the rule that lifts a card holding an open menu above its neighbours; the toolbar's new flex layout, in which the left section takes the room the search bar leaves; and the Deus Ex Machina classes (`qt-chat-established-fact`, `qt-chat-established-fact-row`, `qt-chat-established-fact-band`, `qt-chat-message-established-fact`, `qt-chat-composer-established-fact` and `qt-chat-established-fact-toggle`). A new `deus-ex-machina` icon draws a game-master's screen, and Madman's Box (bundle 1.1.10) overrides it with an eye in a triangle. A theme that paints its page background transparent should check that its popovers now use `--qt-popover-bg`. The search highlight paints through `::highlight(quilltap-conversation-search)`.

### Dependencies

TypeScript 6, ESLint 10, Lexical 0.53, croner 11 and jest-fetch-mock 4.2 arrive in the root. The packages and plugins were brought up to the root's levels, including major bumps for `@google/genai` (2.x), `@anthropic-ai/sdk` (1.x), `html-to-text` (10) and the MCP plugin's `zod` (4). The SVAR file-manager beta is removed, with its dependency. TypeScript 7, `@types/node` 26 and `emojibase-data` 18 are held back, with reasons recorded.

## Repairs

This is the first release whose bugs are GitHub issues rather than entries in the in-repo catalogue. The larger repairs are covered above. The rest:

A file move matched by its hash could be undone a moment later by the old path's pending delete, which removed the moved record. The Scriptorium's ⋮ menu could close the instant it opened, because focusing its first entry scrolled the pane behind it. The wardrobe's slot picker now announces itself as a menu. And the Anthropic plugin no longer defaults older models' temperature to 1.0, since it no longer sends a temperature at all.

## Upgrading

**Four migrations run on first boot.** They add the established-fact flag to messages, add *Most images per request* to connection profiles (existing profiles get 4), remove `temperature`, `top_p` and `top_k` from Anthropic profiles, and rebuild the message search index without the Staff's rows. The last one reads every message once, so it can take a little while on a large instance.

**Anthropic profiles lose temperature and top-p.** The new API version refuses them, so they are removed from existing profiles and hidden in the editor. Older Claude models that used to receive them now sample at Anthropic's defaults. Max tokens and provider options are kept. The SDK now sends your key as `Authorization: Bearer` rather than `X-Api-Key`; Anthropic accepts both, but a proxy in between that looks for `X-Api-Key` will need changing.

**At most four images per request, until you say otherwise.** Every existing profile gets a cap of 4. A turn that used to send more now sends the newest four and describes the rest. If your model takes more, raise *Most images per request* in the profile.

**`npx quilltap` on Linux needs glibc 2.35 or newer** (Ubuntu 22.04, Debian 12, RHEL 9). Older hosts should use the Docker image. macOS, Windows, Docker and the desktop shell are unaffected.

**Global search shows less.** Staff whispers and announcements no longer appear among search results. They are still in your transcripts, and the search bar's *This conversation* group still finds them in an open chat.

**Multi-character chats miss the prompt cache once.** The group-scene rules changed, so each multi-character chat's next turn rebuilds its cached prefix. One-on-one chats are unaffected. No prompt-builder version changed, and established facts ride in the uncached tail, adding nothing to a chat that has none.

**Existing characters keep their prompts.** The probation fix changes the generators and the shipped sample prompts, not anything you have already written or copied. The Character Optimizer's refine pass will find probation behaviour in an existing character's prompt.

**Google profiles may wait longer.** The Google SDK 2.x no longer applies a five-minute timeout when the profile sets none, so a call can run until Google's own limit. Its automatic continuation can also make a very long reply report its prompt tokens more than once.

**Scheduled autonomous rooms around daylight-saving changes.** A schedule that falls in the spring-forward gap now runs at the first valid time after it, and an interval schedule runs through both copies of the repeated autumn hour.

**What backups carry.** Established facts, the established-fact flag and *Most images per request* travel in `.qtap` exports and backups, and older archives restore with the cap set to 4.

Node.js 24+ is still required, unchanged from 4.11.

## Installation

### Electron Desktop App

Download the latest `.dmg` (macOS), `.exe` (Windows), or `.AppImage` (Linux) from the [quilltap-shell releases page](https://github.com/foundry-9/quilltap-shell/releases/latest). The window is only ever a front end, and it offers three back ends: **Direct** (the Node server inside Electron, no isolation), **Docker** (the container image behind a native window, which is the recommended setup and the strongest boundary we ship), and **Remote** (any Quilltap URL, including a dev server, an `npx quilltap` instance, or a machine on your network). Requires shell 4.2.0 or later.

### npm (Node 24 required)

```bash
npm install -g quilltap
quilltap
```

Open `http://localhost:3000` in your browser. Requires Node.js 24+, and on Linux glibc 2.35+. First run downloads and caches locally.

### Docker

```bash
docker pull foundry9/quilltap:4.12.0
```

Or use the startup scripts:

```bash
# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/foundry-9/quilltap-server/refs/heads/main/scripts/start-quilltap.sh | bash

# Windows (PowerShell)
irm https://raw.githubusercontent.com/foundry-9/quilltap-server/refs/heads/main/scripts/start-quilltap.ps1 | iex
```

### Standalone Tarball

Available for environments where npm global installs and Docker are both impractical. See the GitHub releases page for download links.
