# Quilltap 4.14.1 Release Notes

It transpires that the Commonplace Book has spent the better part of a week sending its letters with far too many stamps on them, and the post office, being a stickler, has been returning every one. A connection profile's maximum output was passed along exactly as written, even when it was rather more than the provider would take. Z.AI refuses anything over 131,072 tokens, so one GLM profile set to nearly a million made memory extraction, consolidation and the episode passes fail on every call, some five thousand seven hundred times on a single instance. A cheap-LLM call on a `Deep`-class profile came to grief more quietly: it added four thousand tokens of thinking room on top of a budget already at the ceiling, and NanoGPT and DeepSeek turned it away. In 4.14.1 every request is trimmed to what the provider will accept, as its own model catalogue reports it or as its plugin declares (the Z.AI plugin, 1.1.41, now declares 131,072). The thinking room stops at the profile's ceiling, and your profile's stored setting is left exactly as you wrote it. Memory upkeep on those profiles should simply begin working again, with nothing for you to do.

Three smaller matters were put right while the stamps were being counted. The summary files a chat leaves in each participant's vault kept the title the chat bore at its last summary, long after it had been renamed, so recall kept citing conversations by old names. They are now renamed to match at startup, and their embeddings are not disturbed by it. The conversation cards on a character's **History** tab used to preview whatever message came last, often a Staff whisper that said nothing about the chat; they now show the summary line, as the home page's resume card does. And the custom-tool wand, the `/` commands and the run dialog now notice at once when an equip, a Pascal effect or a tool call changes which tools a chat may use, where before they waited until the tab was closed and reopened. No data or export format has changed.

## Installation

### Electron Desktop App

Download the latest `.dmg` (macOS), `.exe` (Windows), or `.AppImage` (Linux) from the [quilltap-shell releases page](https://github.com/foundry-9/quilltap-shell/releases/latest). The window is only ever a front end, and it offers three back ends: **Direct** (the Node server inside Electron, no isolation), **Docker** (the container image behind a native window, which is the recommended setup and the strongest boundary we ship), and **Remote** (any Quilltap URL, including a dev server, an `npx quilltap` instance, or a machine on your network). Requires shell 4.2.0 or later; 4.2.7 or later is recommended, since it builds its menu bar from the rail's menus and keeps the server on localhost unless you tick **Open to the network** on the splash screen.

### npm (Node 24 required)

```bash
npm install -g quilltap
quilltap
```

Open `http://localhost:3000` in your browser. Requires Node.js 24+, and on Linux glibc 2.35+. First run downloads and caches locally.

### Docker

```bash
docker pull foundry9/quilltap:4.14.1
```

Or use the startup scripts:

```bash
# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/foundry-9/quilltap-server/refs/heads/main/scripts/start-quilltap.sh | bash

# Windows (PowerShell)
irm https://raw.githubusercontent.com/foundry-9/quilltap-server/refs/heads/main/scripts/start-quilltap.ps1 | iex
```

### Standalone Tarball

Available for environments where npm global installs and Docker are both impractical. See the GitHub releases page for download links.
